Proposed dialog system — native OpenTUI mockups

Updated 2026-10-14 for Madison's decisions: borderless tinted panels over a dimmed app, sheets below 30 rows, inline merge confirmation, a Keys tab instead of Help, no Ctrl+X menu, and Esc that closes a dialog while its write keeps going. Key menus are non-modal, so the app behind them stays undimmed.

Each image is a real OpenTUI/Yoga frame rendered headlessly from mockups.tsx over the dimmed real app frame, rasterized with the same Menlo span renderer as the audit captures (thin vertical seams between spans are a rasterizer artifact in both sets). They prove geometry and hierarchy, not final copy or production code. Plan: docs/plans/menu-modal-unification.md.
